Diagram

A diagram is a with block. Resources created inside it belong to that diagram, and >> draws the arrow. The SVG is written when the block ends. Groups are context managers too, so the indentation is the architecture. The second argument is the SVG path. Leave it out and the file is named from the title.

ArgumentWhat it does
direction="LR"Left to right. "TB" flows top to bottom.
spacing="regular"Also "compact" or "relaxed".
align="top"Resources in a step share the top. "center" centers them.
subtitle="Production"A line under the title.
as_of="12 Nov 2026"Prints “as of” on its own line under the icon credit. A datetime.date is formatted for you.
autosave=FalseKeeps the SVG in memory until you call save.
 
from datetime import date
from infrasketch import Diagram, Https, Private
from infrasketch.azure import (
    ResourceGroup, VNet, Subnet, PrivateNetwork,
    Users, FrontDoor, StaticWebApp, AppService, Redis, SQLDatabase, KeyVault,
)

with Diagram(
    "Web, API, and Redis",
    "platform.svg",
    subtitle="Production · West Europe",
    as_of=date(2026, 11, 12),
    autosave=False,
) as diagram:
    customers = Users("Customers")
    with ResourceGroup("rg-edge"):
        door = FrontDoor("Entry")
    with ResourceGroup("rg-app"):
        with VNet("vnet-app"):
            with Subnet("snet-web"):
                web = StaticWebApp("Storefront")
            with Subnet("snet-api"):
                api = AppService("Orders API")
            with PrivateNetwork("data"):
                cache = Redis("Sessions")
                database = SQLDatabase("Orders")
                vault = KeyVault("Secrets")

    customers >> Https() >> door >> web >> api
    api >> [cache, database]
    api >> Private("secrets") >> vault

svg = diagram.svg()
diagram.save("platform.svg")

Leave as_of out and the footer is only the icon credit.

Nodes

A node is one resource. The icon says which service it is. The label is your name for that piece of the system, and the caption under it is the service name.

Azure resources live in infrasketch.azure. AWS resources live in infrasketch.aws. Services outside both clouds live in infrasketch.external. The icon browser groups the external marks into source control and DevOps, CDN and edge, containers, observability, security, messaging, databases, data and analytics, and SaaS.

from infrasketch.azure import AppService
from infrasketch.aws import Lambda
from infrasketch.external import Cloudflare, GitHub

api = AppService("Orders API")
worker = Lambda("Checkout")
repo = GitHub("Orders")
edge = Cloudflare("Primary")

AppService("Orders API") labels the box "Orders API" and captions it "App Service". AppService() uses the service name as the only label. caption=False hides the caption.

A review needs more than the service name. These fields are optional. Leave them out and the box is unchanged.

FieldWhere it appears
skuSecond caption, with the region and exposure
regionSecond caption
public=TruePrints “Public”. False prints “Private”.
noteIts own line under the caption
hrefMakes the icon a link. Only http and https links are accepted.
 
api = AppService(
    "Orders API",
    sku="P1v3",
    region="West Europe",
    public=False,
    note="Private endpoint only",
    href="https://learn.microsoft.com/azure/app-service/overview",
)

A resource with no icon draws a neutral placeholder. Pass icon a picture file to draw that resource with your own artwork. SVG, PNG, JPEG, GIF, WebP, BMP, and ICO all work. The picture is fitted inside the icon square without cropping or stretching. The same argument replaces the icon of a named resource. Azure and AWS icons stay at their original colors and proportions when you do not pass icon.

from infrasketch import Node

billing = Node("Billing", icon="billing.png", caption="Own service")
api = AppService("Orders", icon="logo.ico")

See . The icon browser shows the import line for every icon. From a terminal, python -m infrasketch search cosmos prints the same line. A diagram credits only the marks it actually draws.

Edges

CodeResult
a >> bArrow from a to b
a >> [b, c]Arrow from a to each target
[a, b] >> cArrow from each source to c
a << bArrow pointing back at a
a - bLine with no arrowhead
a >> Edge("SQL", style="dashed") >> bLabelled connector
a >> Https() >> bBlue HTTPS
a >> Async("enqueue") >> bDashed queue or event
a >> Private() >> bDashed Private Link, with no label unless you pass one
a >> Https("Open the store", 1) >> bNumbered step. The sentence is listed under the drawing

style is "solid", "dashed", or "dotted". color is a hex color such as "#0078D4". Https, Async, and Private take the same label, number, color, and style as Edge. Hovering a resource fades the other resources and the arrows that do not touch it.

The step number is a positive integer. The circle is drawn on the line, and the sentence appears once in the legend. The number in the legend jumps to that circle. Repeating the same number and sentence does not add a second row.

door >> Https("Front Door calls the API", 2) >> api

Boundaries & Groups

Import Azure boundaries from infrasketch.azure and AWS boundaries from infrasketch.aws. Group comes from infrasketch and draws a box that belongs to neither cloud. A group takes sku, region, public, and note on the title band. Groups do not take a link.

Azure

GroupUse it for
Subscription("sub")A subscription
ResourceGroup("rg-app")A resource group
Region("West Europe")A region
VNet("vnet-app")A virtual network
Subnet("snet-api")A subnet
PrivateNetwork("data")Private endpoints or Private Link

AWS

GroupUse it for
AWSCloud("aws")The AWS cloud
Account("prod")An account
Region("eu-west-1")A region
VPC("vpc-app")A virtual private cloud
PublicSubnet("public")A public subnet
PrivateSubnet("private")A private subnet
AutoScaling("workers")An Auto Scaling group

Every boundary starts open, and its title is a button. Click the title, or focus it and press Enter or Space, to close the box, and do the same again to open it. A keyboard focus draws a ring on the box. This is the same for a resource group, a virtual network, a subnet, a VPC, and the other boundaries.

folded=True starts that box closed. The resources stay in the model, the box shows how many there are, and a connector from outside lands on the box. foldable=False leaves a boundary fixed. Open the SVG in a browser; an image preview does not run the click. Lines that start and end inside a closed box are not drawn. If a diagram has too many boundaries to open and close, set foldable=False on the ones that should stay fixed.

from infrasketch import Diagram, Private
from infrasketch.azure import AppService, Monitor, ResourceGroup, Subnet, VNet

with Diagram("Orders", "orders.svg"):
    with ResourceGroup("rg-app"):
        with VNet("vnet-app", folded=True):
            with Subnet("snet-api"):
                api = AppService("Orders API")
    with ResourceGroup("rg-observe"):
        alerts = Monitor("Alerts")

    api >> Private("The API reports failures") >> alerts

Inside a boundary, connected resources flow in the diagram direction. Resources at the same step stack. arrange="row" forces a single row, arrange="column" a single column, and arrange="grid" with columns=3 a grid. A short last row is centered under the rows above it. direction and align on a group override the diagram for that box.

with ResourceGroup("rg-shared", arrange="grid", columns=3):
    vault = KeyVault("Keys")
    files = StorageAccount("Files")
    health = Monitor("Health")
    logs = LogAnalytics("Logs")
    traces = ApplicationInsights("Traces")
