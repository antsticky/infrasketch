Install

Python 3.10 or newer. There are no runtime dependencies.

pip install infrasketch

A diagram is a with block. Resources created inside it belong to that diagram, and >> draws the arrow. The SVG is written when the block ends.

Azure

Azure resources live in infrasketch.azure. ResourceGroup, VNet, Subnet, and PrivateNetwork are boundaries. The icon says which service it is. The label is your name for that piece of the system, and the caption under it is the service name.

from infrasketch import Diagram, Https, Private
from infrasketch.azure import (
    ResourceGroup, VNet, Subnet, PrivateNetwork,
    Users, FrontDoor, StaticWebApp, AppService, Redis, SQLDatabase, KeyVault,
)

with Diagram("Web, API, and Redis", "platform.svg", subtitle="Production · West Europe"):
    customers = Users("Customers")
    with ResourceGroup("rg-edge"):
        door = FrontDoor("Entry")
    with ResourceGroup("rg-app"):
        with VNet("vnet-app"):
            with Subnet("snet-web"):
                web = StaticWebApp("Storefront")
            with Subnet("snet-api"):
                api = AppService("Orders API")
            with PrivateNetwork("data"):
                cache = Redis("Sessions")
                database = SQLDatabase("Orders")
                vault = KeyVault("Secrets")

    customers >> Https() >> door >> web >> api
    api >> [cache, database]
    api >> Private("secrets") >> vault

AWS

AWS resources live in infrasketch.aws. VPC, PublicSubnet, and PrivateSubnet are boundaries. The label and caption work the same way as on an Azure resource.

from infrasketch import Diagram
from infrasketch.aws import (
    APIGateway, CloudFront, DynamoDB, Lambda, PrivateSubnet, PublicSubnet, S3, Users, VPC,
)

with Diagram("Orders", "orders.svg", subtitle="Production · eu-west-1"):
    customers = Users("Customers")
    edge = CloudFront("Entry")
    with VPC("vpc-orders"):
        with PublicSubnet("public"):
            api = APIGateway("Orders")
        with PrivateSubnet("data"):
            checkout = Lambda("Checkout")
            orders = DynamoDB("Orders")
            images = S3("Images")
    customers >> edge >> api >> checkout
    checkout >> [orders, images]

External

Services outside Azure and AWS live in infrasketch.external. Each one is a node. The icon is the service, and the label is your name for that piece of the system. The set is GitHub, Cloudflare, and Akamai.

from infrasketch import Diagram, Https
from infrasketch.azure import AppService, ResourceGroup
from infrasketch.external import Akamai, Cloudflare, GitHub

with Diagram("Edge and source", "edge.svg"):
    repo = GitHub("Orders")
    primary = Cloudflare("Primary")
    failover = Akamai("Failover")
    with ResourceGroup("rg-app"):
        api = AppService("Orders API")

    primary >> Https() >> api
    failover >> Https() >> api
    repo >> api

See examples/external_edge.py and examples/external_github.py. The icon browser lists the import for each mark. A diagram credits only the marks it actually draws.

Draw a diagram

Groups are context managers too, so the indentation is the architecture. The second argument is the SVG path. Leave it out and the file is named from the title.

ArgumentWhat it does
direction="LR"Left to right. "TB" flows top to bottom.
spacing="regular"Also "compact" or "relaxed".
align="top"Resources in a step share the top. "center" centers them.
subtitle="Production"A line under the title.
as_of="12 Nov 2026"Prints “as of” in the footer, after the icon credit. A datetime.date is formatted for you.
autosave=FalseKeeps the SVG in memory until you call save.
 
from datetime import date

with Diagram(
    "Orders",
    "orders.svg",
    subtitle="Production · West Europe",
    as_of=date(2026, 11, 12),
    autosave=False,
) as diagram:
    ...
svg = diagram.svg()
diagram.save("orders.svg")

Leave as_of out and the footer is only the icon credit, the same as before.

Connectors

CodeResult
a >> bArrow from a to b
a >> [b, c]Arrow from a to each target
[a, b] >> cArrow from each source to c
a << bArrow pointing back at a
a - bLine with no arrowhead
a >> Edge("SQL", style="dashed") >> bLabelled connector
a >> Https() >> bBlue HTTPS
a >> Async("enqueue") >> bDashed queue or event
a >> Private() >> bDashed Private Link, with no label unless you pass one
a >> Https("Open the store", 1) >> bNumbered step. The sentence is listed under the drawing

style is "solid", "dashed", or "dotted". color is a hex color such as "#0078D4". Https, Async, and Private take the same label, number, color, and style as Edge.

The step number is a positive integer. The circle is drawn on the line, and the sentence appears once in the legend. Repeating the same number and sentence does not add a second row.

Decisions

A review needs more than the service name. These fields are optional. Leave them out and the box is unchanged.

FieldWhere it appears
skuSecond caption, with the region and exposure
regionSecond caption
public=TruePrints “Public”. False prints “Private”.
noteIts own line under the caption
hrefMakes the icon a link. Only http and https links are accepted. Groups do not take a link.
 
api = AppService(
    "Orders API",
    sku="P1v3",
    region="West Europe",
    public=False,
    note="Private endpoint only",
    href="https://learn.microsoft.com/azure/app-service/overview",
)
door >> Https("Front Door calls the API", 2) >> api

A group takes sku, region, public, and note on the title band. See examples/azure_decisions.py and examples/aws_decisions.py.

Folded groups

folded=False is the default, so a boundary draws every resource inside it. Pass folded=True when the box should start closed: the resources remain in the model, the box shows how many there are, and a connector from outside lands on the box.

with ResourceGroup("rg-observe", folded=True, foldable=True, note="Click to open"):
    alerts = Monitor("Alerts")
    logs = LogAnalytics("Workspace")

api >> Private("The API reports failures", 4) >> alerts

foldable=True makes the title a button in the SVG. Click it to open the box, and click the title again to close it. folded is only the state it starts in. Open the SVG in a browser; an image preview does not run the click. Lines that start and end inside a closed box are not drawn. See examples/azure_folded.py.

Boundaries

Import Azure boundaries from infrasketch.azure and AWS boundaries from infrasketch.aws. Group comes from infrasketch and draws a box that belongs to neither cloud.

Azure

GroupUse it for
Subscription("sub")A subscription
ResourceGroup("rg-app")A resource group
Region("West Europe")A region
VNet("vnet-app")A virtual network
Subnet("snet-api")A subnet
PrivateNetwork("data")Private endpoints or Private Link

AWS

GroupUse it for
AWSCloud("aws")The AWS cloud
Account("prod")An account
Region("eu-west-1")A region
VPC("vpc-app")A virtual private cloud
PublicSubnet("public")A public subnet
PrivateSubnet("private")A private subnet
AutoScaling("workers")An Auto Scaling group

Inside a boundary, connected resources flow in the diagram direction. Resources at the same step stack. arrange="row" forces a single row, arrange="column" a single column, and arrange="grid" with columns=3 a grid. direction and align on a group override the diagram for that box.

Names

Common Azure names come from infrasketch.azure: FunctionApp, ContainerApp, ACR, AKS, Redis, SQLDatabase, KeyVault, FrontDoor.

Common AWS names come from infrasketch.aws: Lambda, EC2, S3, DynamoDB, RDS, APIGateway, CloudFront, EKS.

External names come from infrasketch.external: GitHub, Cloudflare, and Akamai.

Every icon in these sets is included. The icon browser shows the import line. From a terminal:

python -m infrasketch search private endpoint
python -m infrasketch categories
from infrasketch import search

for hit in search("cosmos"):
    print(hit.import_line)

FunctionApp("Orders") labels the box "Orders" and captions it "Function App". FunctionApp() uses the service name as the only label. caption=False hides the caption.

A resource with no icon draws a neutral placeholder. Pass icon="path/to.svg" to use your own artwork. Azure and AWS icons stay at their original colors and proportions.
