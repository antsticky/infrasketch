Draw the architecture as SVG.

infrasketch places official Azure resource icons on a white canvas and routes the connectors itself. Graphviz is not required.

Browse the icons Read the guide 
from infrasketch import Diagram, FrontDoor, FunctionApp, Redis, ResourceGroup

with Diagram("Orders", "orders.svg"):
    with ResourceGroup("rg-app"):
        web = FrontDoor("Frontend")
        api = FunctionApp("API")
        cache = Redis("Sessions")
    web >> api >> cache
